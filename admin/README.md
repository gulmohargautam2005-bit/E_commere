# Admin Dashboard

This is the admin dashboard application for HOTASH, built as a separate React application.

## Installation

```bash
npm install
```

## Running the Application

```bash
npm start
```

The application will run on http://localhost:3000 (or the next available port).

## Building for Production

```bash
npm run build
```

## Structure

- `src/AdminApp.js` - Main application component with routing
- `src/components/` - Reusable components (AdminLayout, AdminSidebar, AdminHeader)
- `src/pages/` - Page components (AdminDashboard)
